Reliability Engineering

回测跑通，不等于结果可信

量化最贵的错误不是策略亏钱，而是拿一个虚高的回测去配真金白银。 框架在三个层面做了防护，并给出可验证的实测数据。

防线 1

引擎时序：信号延迟一期、次日开盘成交

策略用 t 日收盘价算信号，就只能在 t+1 开盘成交——默认 execution_lag=1 + fill_price="open"。信号与成交同日的旧做法，实盘做不到。

防线 2

策略自检：40 个策略逐个查未来数据引用

未来扰动法——截掉后段 K 线，前段信号必须一字不变。任何策略若用全样本均值/标准差定参数，会被立刻抓住。

防线 3

指标自检：41 个指标同样口径

技术指标是策略的输入，含前视会污染下游一切回测。已查出并修掉 renko 用全样本极差定砖块尺寸的问题。

结果可信度体检

跑完自动检查 8 类不可信信号：样本过短、交易过少、零成本假设、夏普 >3、收益很高却几乎无回撤、年化 >100%……翻译成人话告诉你。

样本外验证

按时间切分前 60% 观察、后 40% 验证，输出衰减率与判定：稳健 / 减弱 / 疑似过拟合 / 无明显优势。区分「真有效」和「参数拟合出来的好结果」。

833 项自动化审计

对抗性输入驱动每一个量化方法：策略输出必须 ∈ {-1,0,1}、优化器权重和必须 ≈1、退化输入下零容忍 inf 与崩溃。

Features

从研究到实盘，链路是通的

四资产统一入口

股票、基金、期货、期权共用一套 run_backtest(symbol, strategy) 调度器，自动识别资产类型并路由到对应引擎。

零重依赖核心

回测引擎只依赖 pandas / numpy。akshare、baostock、streamlit 均为可选，断网时自动降级并如实标注数据为演示数据。

实盘链路完整

信号 → 盘前风控 → 下单 → SQLite 账本 → 账户快照。支持 QMT / PT 真实柜台（需显式 live=True）、多账户路由、盘中止损止盈与企业微信推送。

小白也能用

向导式命令行：跟着提示选就行，直接回车用默认值。输出不仅给收益，还告诉你结果可不可信、下一步该看什么。

注册表驱动扩展

新增策略 / 优化器 / 指标 / 绩效 / 风险 / 因子，只要在对应注册表登记，终端界面与自检流程自动发现。

服务生命周期治理

终端守护崩溃 2 秒自愈；停止逻辑按 supervisor → terminal → backend 顺序关停，先杀守护者阻断自愈，不会出现「点了停止又活过来」。
